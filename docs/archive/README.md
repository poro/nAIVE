# Archive

Earlier plans, pitches and assessments, kept for history. They describe
plans and claims the code does not implement (multiplayer, the AI Director,
the natural-language compiler, "100x faster" iteration and others), and some
are out of date. For what nAIVE does today see the implementation status in
the [README](../../README.md); for how to use it see the
[game development guide](../GAME_DEVELOPMENT_GUIDE.md).
