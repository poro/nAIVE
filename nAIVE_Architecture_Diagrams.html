Engine Game Loop
One frame of the main loop — from input capture through rendering. Runs inside the winit event loop.
1. Frame Timing
Calculate delta_time from last frame. Cap at reasonable maximum to prevent physics explosions.
engine.rs → resumed()
2. Hot-Reload Check
File watcher detects changes to scenes, scripts, shaders, materials. Triggers recompilation or reconciliation.
watcher.rs → poll_events()
3. MCP Command Processing
Read pending commands from TCP socket (:6969). Execute spawn, destroy, modify, run_lua, save_scene, etc.
command.rs → process_commands()
4. Input Capture
Process keyboard/mouse events from winit. Map physical keys to semantic actions via bindings.yaml. Handle synthetic injected input.
input.rs → update()
5. Lua Script Updates
Call update(dt) on every entity with a script component. Scripts push commands to EntityCommandQueue (deferred).
scripting.rs → update_all(dt)
6. Physics Step
Rapier3D simulation step. Detect collisions and triggers. Sync physics body positions back to ECS transforms.
physics.rs → step(dt) + sync_to_ecs()
7. Collision & Damage Events
Process new collision/trigger events. Apply collision damage. Fire on_collision, on_trigger_enter/exit, on_damage, on_death callbacks.
engine.rs → handle_collisions()
8. Deferred Command Queue
Process EntityCommandQueue: execute spawns first, then destroys. This ordering prevents dangling references.
world.rs → process_commands()
9. Tweens & Animation
Advance tween interpolations. Tick skeletal animation controllers. Compute bone matrix palettes.
tween.rs + anim_system.rs → tick()
10. Particle Simulation
Spawn new particles from emitters. Apply gravity, age, interpolate color/size. Cull expired particles.
particles.rs → update(dt)
11. Camera Update
Update camera position/rotation based on mode (first-person, third-person, editor fly-cam). Apply camera shake.
camera.rs + editor_camera.rs
12. Render Frame
Write per-entity draw uniforms. Execute forward render pass (PBR materials + depth). Render particles as billboards. Render Gaussian splats. Draw UI overlay.
renderer.rs + pipeline.rs → render()
13. Audio Update
Update listener position. Process spatial attenuation for 3D sounds.
audio.rs → update_listener()
14. Present
Submit GPU command buffer. Present swapchain frame. Clear per-frame state (just_pressed, events).
wgpu surface.present()

Lua Scripting Architecture
Per-entity sandboxed Lua 5.4 with 40+ API functions across 9 namespaces.
Lifecycle Hooks
Script Callbacks
init() — entity spawned update(dt) — every frame fixed_update(dt) — physics substep on_collision(other_id) on_trigger_enter(other_id) on_trigger_exit(other_id) on_damage(amount, source_id) on_death() on_destroy()
Safety Model
Sandboxing & Deferred Commands
Each entity gets its own Lua environment with self table for persistent state. Dangerous stdlib disabled (os, io, loadfile, dofile). All world mutations go through EntityCommandQueue — processed end-of-frame.

Tier Roadmap
Development tiers, each validated by proof games. Proof game: HAVOC (3D Vampire Survivors with vehicle combat).

Tier 1 — Gameplay Primitives · v0.1.2
Health, Hitscan, Projectiles, Collision Damage, Third-Person Camera
Core combat loop. Validated by HAVOC prototype (built in single session). Health/damage system, hitscan raycast with entity hit detection, physics-driven projectiles with auto-damage, collision damage component, third-person orbit camera with wall avoidance.
DONE Combat Demo Third-Person Demo
Tier 2 — Production Foundations · v0.1.4
Dynamic GPU Buffer, Entity Pooling, Particles, Tag Queries, Events
Removed HAVOC hard walls. Dynamic instance buffer (no 256-entity ceiling), entity pooling for projectile recycling, CPU particle system, runtime entity queries by tag, event subscription from Lua.
DONE Stress Test (300+) Lifecycle Demo Particle Demo
Tier 2.5 — Physics & Scene API · v0.1.7
Impulse/Force, Velocity, CCD, Collider Materials, Camera Shake, Scene Loading
Full physics API for Lua scripts. Apply forces/impulses, get/set velocity, continuous collision detection for fast projectiles, friction/restitution materials, camera shake effects, runtime scene transitions.
DONE Impulse Demo CCD Demo Materials Demo
Tier 2.75 — Editor & AI Assets · v0.1.11
Editor Mode, MCP Tools, AI Asset Pipeline, Skeletal Animation Data, Beautify
The "AI is the editor" milestone. Free-fly editor camera, 15 MCP tools for scene control, text-to-3D asset pipeline (FLUX→Hunyuan/Meshy→GLB), skeletal animation data structures and bone palette computation, scene beautification pipeline (mesh→splat). 17 embedded demos.
DONE naive edit Meshy Demo Submarine Demo
Tier 3 — GPU Scale · Next
50,000+ GPU Compute Entities, Neighbor-Grid Collisions, Flow Field Pathfinding
nAIVE's answer to Unreal's Niagara — but for gameplay entities, not just particles. GPU compute shaders simulate hordes/swarms with collision detection and pathfinding. CPU ECS for players/bosses, GPU for masses. Deferred rendering pipeline with shadows, bloom, tonemapping.
IN PROGRESS HAVOC Hordes Shadow Mapping Deferred PBR
Tier 4 — Animation & Polish
Skeletal Animation Rendering, VAT, UI Widgets, State Machines
Skinned mesh rendering on GPU, animation state machines with blend trees, Vertex Animation Textures for GPU-instanced hordes, proper UI widget system (menus, inventory). Data structures exist — rendering needs wiring.
Planned Skeleton ✓ (data) Rendering ✗
Tier 5 — Game Systems
Vehicles, Mounted Weapons, Inventory, Loadout, Multiplayer
Complete game systems for HAVOC: drivable vehicles with collision damage, weapon mounting, inventory/ammo management, loadout system. Server-authoritative multiplayer with client prediction and entity interpolation.
